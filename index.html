Guarda tu Client ID, tu Client Key y tu sesión de Spotify en un archivo para iniciar rápido en otro navegador o dominio (el navegador guarda estos datos por separado en cada uno). El archivo equivale a una contraseña: no lo compartas ni lo subas a ningún repositorio.

Apariencia

Letras

Renderizador de letras

Spicy es el renderizador nuevo, derivado del de Spicy Lyrics y del AMLL TTML Tool (AGPL-3.0). Clásico es el anterior. El cambio se aplica al instante y se guarda en este navegador.

TV y mando

Con el mando: flechas para moverte, OK para elegir y Atrás para volver (en el reproductor, izquierda y derecha sobre la barra de progreso adelantan o atrasan 10 s). Las teclas multimedia (play/pausa, siguiente, anterior) también funcionan. Muchas TV no pueden reproducir audio con el SDK de Spotify: en ese caso activa el control remoto, abre Spotify en tu teléfono o computadora, y la TV mostrará las letras y controlará esa reproducción. El control remoto necesita Spotify Premium.

CSS personalizado

Se aplica al instante y se guarda en este navegador. La base trae ejemplos comentados (fuente, variables, formas): quita el comentario de lo que quieras activar.
